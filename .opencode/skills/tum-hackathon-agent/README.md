# TUM hackathon agent skill

Workspace-local OpenCode skill for the TUM Blockchain & AI Hackathon agent
setup. It walks through the official template, Sokosumi Preprod account setup,
Personal Workspace Task, optional Preprod payment test, TUM Workspace Task, and
demo preparation.

- **Skill ID:** `tum-hackathon-agent`
- **Source:** provided for this workspace; based on the official TUM hackathon
  guide at <https://www.masumi.network/tum-hackathon>
- **Entry point:** `SKILL.md`

OpenCode loads `SKILL.md` when the skill is invoked. Use the `masumi` skill for
deeper Masumi payments, registry, identity, and Sokosumi marketplace reference
material.
